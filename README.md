# Ghosla

A collection of artful agentic instructions.

I find it pointless that using a skill has essentially become copy pasting for me. I don't know _how_ it works, I don't know _why_ it works. Abstractions over abstractions, over abstractions.

I feel this defeats the purpose of skills, which are ideally supposed to be recipies of workflows for agent harnesses. Now, if you don't know _how_ to cook, what use is the recepie? Yes, you can prepare the dish, you can experiment a bit as well but it won't be the same if you had spent time learning the ins and out of the recepie, asking yourself _why_ is it written the way it is.

That being said, the above can be done by agents as well - that is what I do. So, the idea behind this repository is to add my skills and vendored skills to explore the boundaries of agent instructions to further my understand. Acknowledging I may lack behind agents, but at least I am still human in the loop, and that too requires constant plumbing.
